Experimental local trust-auth-only PostgreSQL protocol probe. It sends original SQL with explicit text OID25 Parse parameters and native Bind bytes, retaining original result frame bytes and exact text/null cells. Only loopback connections are admitted; no TLS/password authentication, cancellation/pool/recovery or complete preallocation account is implemented. It is a component transport experiment, not the qualified production driver or engine.

Protocol source: [PostgreSQL17 message formats](https://www.postgresql.org/docs/17/protocol-message-formats.html). Integer values in protocol framing are metadata; stored values remain exact text. Response limits reject excessive/malformed messages, but native socket chunk allocation and enclosing-account guarantees remain unqualified.
