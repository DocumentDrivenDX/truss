# Module-policy overhead experiment — candidate

This protocol serves US-037-AC6 and STP-037 under TP-001. The criterion's
0.01 ms target is retained. The measurement statistic and exact environment
below are proposed registration inputs, not an adopted performance profile or
executed evidence. Security semantics and admission remain owner-supplied.

Use 1,000 types distributed evenly across ten modules, with one required string
field and one object per type. Keep the complete 1,000-object inventory, native
indexes/statistics, value bytes and selected read-by-id request equivalent in
both arms. Select one object in sales, bind its original identity through an
admitted fixture alias, and author its complete expected value before collecting
implementation outputs. No unsupported scalar/optional/retained payload enters
one arm alone.

The policy arm has the original selected module layer and an ordinary sales
reader. The baseline is a separately qualified installation of the optional
layer-not-applied profile using the equivalent ordinary reader role and admitted
read path. The security owner must admit both compositions and their exact
differences. Never disable guards on a live policy installation, substitute a
SUPERUSER/BYPASSRLS role or introduce a handwritten query to manufacture a cheap
baseline. Required original actor, integrity, decoding, resource and publication
checks remain accounted in each arm. If no valid baseline composition exists,
record the experiment unavailable rather than substituting one.

Before timing, independently verify the measured complete sales result in both
arms. Separately verify policy-arm refusal of billing writes, reader writes and
unauthorized row disclosure across all protected homes. These semantic checks
are correctness prerequisites, not overhead measurements; a cheap incorrect
policy cannot pass AC6. Capture exact statement/parameter/binding, owner-policy,
grant, native privilege and original context/profile bytes for both arms.

Measure monotonic public-call elapsed time from original capability entry until
the complete decoded result is admitted for return, under matched held-read
contexts. Include policy/current-authority participation and publication checks;
exclude installation, pool checkout and context construction in both arms, and
publish those exclusions. Different managed services, security profiles or driver
modes require separate registrations.

Propose three blocks, each with 30 unmeasured warm-up pairs and 1,000 measured
pairs, alternating arm order and reversing the first arm in block two. Preserve
exact integer nanoseconds and signed policy-minus-baseline differences. The
proposed statistic passes a block when its sum is at most 10,000,000 ns, equivalent
to mean incremental cost at most 10,000 ns (0.01 ms); no float/rounding or dropped
negative differences. Require all three original blocks. Preserve raw order,
median/p95/maximum and every error/interruption; missing/incorrect samples
invalidate a block rather than being replaced. This proposed mean statistic
requires explicit registration before execution and is not inferred from the
separate pending pooler-overhead choice.

Seal original fixture, environment, timer resolution, snapshots, cache/statistics,
transport and complete security/native obligations before running. Exercise
exact threshold/one-nanosecond-over, missing-sample, wrong-result and baseline
bypass controls. The runner, admitted baseline/profile tuple and independent
native measurements remain unimplemented. Timing evidence cannot qualify
authorization, publisher retirement or general read-path enrollment.
