# Corpus alias comparison — candidate 0.1

This language-neutral procedure supports US-027-AC3 and consumes CONTRACT-004's
corpus manifest. It is an authored harness procedure, not a production identity
registry, authority grant or passing interchange receipt.

Each original case declares symbolic identities and their typed namespace:
source epoch, entity kind and owning type/relationship definition where required
by the selected identity contract. Declare the operation/result field that first
binds each allocation. Required existing-fixture aliases have independently
observed bindings before operations. An alias binds once to one admitted native
identity under that namespace; rebinding to another identity refuses comparison.
Two declared distinct aliases cannot bind the same complete identity. Equal
numeric IDs in genuinely different admitted namespaces are not a collision.
Do not invent namespace distinctions to hide an actual same-identity conflict.

Alias substitution applies only to paths identified as generated identity
references by the selected operation/result/state/journal/report grammar.
A literal text value "$a", an authored element name, source key, numeric token,
opaque artifact or unknown extension is data and remains exact. No recursive
string replacement or name-based inference. Unknown required grammar makes
comparison unavailable rather than leaving guessed fields unchecked.

Before normalization, independently validate complete identity domains,
original source/definition correspondence and every required equality,
distinctness, reference, ordering and committed-nonreuse relation. Native numeric
order uses exact integer arithmetic; alias spelling is not its comparator.
Normalization cannot erase a duplicate identity, wrong endpoint, foreign epoch,
reused committed allocation, missing row or changed row multiplicity. Corpus
expectations avoid allocator-specific numeric literals while still testing these
relations. Provisional rollback gaps are a separately selected allocation rule,
not automatic committed nonreuse evidence.

Apply the same admitted mapping to expected and actual typed structures, then
compare all required result/state/journal/report fields under their original
profiles. Preserve operation and semantic sequence order; sort only collections
whose grammar explicitly declares order immaterial. Unbound required references
fail; no new alias may be derived from the observed result merely to make it
match. Digests, counts or matching final state cannot replace original event or
report comparisons. Native observations remain independent of the implementation.

For interchange, retain A's committed original alias-to-identity correspondence
and independently admit B's observation over that exact source installation.
B reads A's actual identities; it cannot allocate substitute rows or create a new
mapping from its own decoder. Repeat independently with B writing and A reading.
Current authority and exact original schema/codec/profile support remain required.

Independent controls bind two allocator permutations to equivalent states,
substitute a wrong typed endpoint, collapse two distinct allocations, retain a
literal "$a" property value, overlap object/edge numeric IDs legitimately, and
change only native ID ordering. Equivalent permitted allocations pass;
identity/data/invariant substitutions fail. The exact case alias artifact
encoding/profile and runner remain to be registered and executed.
