Existing source markers or epochs require migration; there is no repair or synthetic epoch insertion. The original native `runtime_issue_source_epoch` allocates and installs the epoch.

The recipe locks epoch homes in ROW EXCLUSIVE mode before metadata locks and locks an existing marker row before recapture. Before invoking original catalog assessment routines, it compares all 158 original runtime routine bodies, native signatures, execution attributes and private execution ACLs against the pinned runtime sources. It captures the complete current accepted document set and validates its native catalog correspondence. Historical registration receipts are validated by the assessment but their original bytes are not separately archived. This checkpoint does not archive a broader UMF core/key codec producer chain.

The profile is expressly catalog metadata and original runtime code only. It does not establish action roles, human identity, object facts, registered selection programs, protected execution or a bulk store epoch.
