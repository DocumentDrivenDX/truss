# Selected preparation bridge definition custody

The private bridge adjunct extends the original metadata cut to an explicit
inventory of the durable UMF claim, Truss program, attempt anchor and store
homes. It enables no execution or permission and adds no production installer,
ordinary coordinator SDK or grants. The initial source profile's 19 metadata
homes and 158 runtime routines do not cover these new objects by implication.

`preparation_bridge_inventory_source()` composes the private SQL template with
the original manifest-checked DDL handler body. D acquires the original source
SHARE cut before any policy evaluation, compatible ROW EXCLUSIVE locks on the
claim/anchor/store homes, and the original program SHARE cut. This allows the
excluded E issuer to insert and commit the claim. D verifies the original
all-tag ALWAYS database DDL barrier, its invoker ABI/body and private ACL.
Supported participating DDL retains conflicting epoch writer locks until
transaction settlement. Catalog relation locks alone are insufficient: a
catalog writer can release its internal lock before committing its changes.

C preacquires ACCESS SHARE NOWAIT before reading selected homes, consumes the
original committed claim internally, verifies its original live D PID/full XID
and currently granted D locks both before and after collection, and returns a
fresh definition inventory for
comparison with D's original inventory. C never reacquires D's SHARE cuts.
Callers must set a short lock timeout before dispatch, including E dispatch;
the helpers also set a 1ms lock timeout for nested acquisitions. Ordinary host
statement deadlines still apply to dispatch. Savepoint rollback can remove a
cut, so earlier success is insufficient.

The inventory contains seven table/sequence homes, column/default definitions,
constraints, index definitions, composite types, triggers, three sequence
definitions, selected routine source and ABI/ACL, namespaces, event triggers and
catalog dependencies. Its writer census records table/routine owners and ACLs,
the original supported DDL participation boundary, and explicit exclusions.
It is an adjunct to existing source admission, not a complete PL/pgSQL semantic
call graph or whole installed profile. Sequence values, shared role writers,
current Subject/action/owner authority and excluded administrative bypass are
outside this definition correspondence. Current permission, the original typed
UMF obligation packet, guarded mint/check and selector/seal composition remain
separate prerequisites. The owner UMF claim SQL stays pinned at `a8f73415` and
is loaded only by the fixture.

The original SCRAM engine D/C and excluded E workflow passes on PostgreSQL18.6,
psycopg3.3.6 and pgserver-pg18 18.6.1. It demonstrates matching D/C inventories,
E commit compatibility, refusal while participating DDL remains uncommitted,
three actual DDL refusals at the epoch barrier, a separately queued explicit
ACCESS EXCLUSIVE lock with bounded C refusal and unchanged D snapshot/full XID,
refusal after rolling back D's cut, and ordinary direct-call refusal. The
fixture grants only its explicit assessor wrapper; production helpers remain
private. The original standalone SCRAM claim test also passes. Inventory bytea rendering is
pinned to hex; comparison passes even when C uses escape output. The retained
[receipt](evidence/preparation-bridge-inventory-20261015/receipt.json) records exact
source hashes and native results. Astra Ultra reviewed the plan and implementation.
