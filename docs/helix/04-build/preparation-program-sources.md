# Original preparation source association

The private source issuer invokes the actual pinned Weft replay and the original
committed UMF host source compiler, then associates the result with the existing
native program. The child row has only the existing `program_id` primary/foreign
key; no new UUID, registration key or copied store registry is introduced.
It retains the complete original owner output, including all fourteen input
artifacts, and the exact producer identity. Its five compiler artifacts must
match the original native program byte for byte, with the same installed store
receipt. The excluded issuer authenticates authored-source provenance; neither
caller output nor a serialized replay receipt replaces producer invocation.

The issuer commits before D begins. Exact retries return the existing pending
association; changed source bytes require a new program even when the owner
compiler accepts their logical meaning. UMF generates the native table, FK,
column definitions, immutable trigger and private ACL from the saved model.
The source compiler comes from the exact committed `98ee88f1` archive. Storage
export separately used clean UMF source/native code at `cbb6fb87` in the original
0e51 checkout; these are distinct producer revisions.

When the child home is installed, the private bridge cut includes it as the
eighth home with D-held SHARE exclusion. D must see the committed original
attachment in its own RR snapshot; C preacquires a nonwaiting read lock and
verifies D's currently granted source-home lock before and after collection.
Both retain the same exact original packet and producer bytes. Durable source
reads use original MVCC visibility from another issuer, not historical CLOG
retention. The older seven-home metadata-only diagnostic fixture remains
supported; it does not qualify a source-aware native guard or permit fallback
when an installed source home lacks its selected program attachment.

One basic PostgreSQL18.6/psycopg3.3.6/pgserver-pg18 18.6.1 workflow passes with
actual original sources, a fresh native binding and both real producers. It
covers enrollment, exact retry, refusal of changed valid sources, eight-home
D/C correspondence, SCRAM D/C authentication and the original bounded-lock
controls. Missing/late attachment refusal is implemented but was not separately
exercised in this basic workflow. Astra Ultra approved this scoped checkpoint.
The metadata-only regression passes separately. See the retained
[receipt](evidence/preparation-program-sources-20261015.json).

The bundle remains host-only and requires Bun during excluded source issuance.
Trusted engine executables, source files and immutable installation custody
remain premises. The original owner result stays `complete:false` and
`authority:false`. Current native human/action/owner authority, shared-role
writer lifecycle, the complete source/legacy/effect closure, guarded mint/check
and protected selection/finalization remain separate. No production installer,
ordinary C SDK grants, current-authority claim or protected execution is enabled.
