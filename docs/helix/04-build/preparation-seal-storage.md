`bootstrap_preparation_seal_storage_in_transaction` installs the 17-column native seal model exported by UMF. The packaged SQL and retained owner export are byte-identical, SHA256 `235f2ce982eeda53eaee09f7608a388f96a815cde5354f4ce6db9bb3091422fe`. This is a private installation adjunct with no ordinary executor grants. The trusted direct superuser owns the enclosing PG18.6 read-write READ COMMITTED transaction and must provide administrative quiescence. Existing seal objects require explicit migration.

The installer preserves epoch ROW EXCLUSIVE → marker → metadata lock order, verifies original runtime code, executes the unchanged owner DDL, and transfers table/sequence ownership to the original unprivileged NOLOGIN runtime owner. It verifies the composite type follows the table owner, all columns/defaults/generated expressions, 14 checks, primary key, immediate attempt uniqueness, original installation foreign key, valid backing indexes, dedicated metadata sequence and its default dependency, original ALWAYS statement immutability trigger, and owner-only table/type/sequence ACLs before returning `pending_commit` and `security_ready=False`.
