# Engine integration with durable data claims

The private Python adapter now consumes the UMF `a8f73415aef8052e2dedeb3bc644426824675d14` excluded-issuer ABI. `capture_preparation_claim_data(session)` captures the actual PID and full transaction ID through the original engine-owned REPEATABLE READ handle, checks writable RR/no SET ROLE and retains the session/handle association. `issue_preparation_data_claim_in_transaction(host, tx, anchor_id=..., anchor_nonce=..., data=...)` reobserves that same data handle before invoking `umf_security.claim_preparation_data`. It returns a pending UUID identity. E's caller owns the independent commit; the adapter performs no commit or retry.

No ordinary coordinator SDK wrapper or direct native grant is added. The future coordinator guard must consume the existing owner-private `require_preparation_data_claim` internally under independently qualified current source and authority. D never reads the later claim row or replaces its snapshot. Missing or unknown E settlement is not rollback and cannot authorize reassignment. The claim identifies the first durably issued D, not proof that no earlier unadmitted D existed, a one-execution permission or an authorization token.

The basic native test uses actual original products acceptance, Weft compilation, store/program enrollment and native anchor creation, followed by the real engine session's pre-RR capture and single RR begin. The excluded adapter's pending result cannot be consumed; after caller commit the fixture-only coordinator assessor sees the exact native tuple. Exact same-D retry returns the same claim. Engine rollback makes coordinator consumption refuse, the adapter refuses a new issue through the ended original handle, and the immutable claim remains. One PG18.6 native test passed in 6.249s. This uses the generic local native login to test engine lifecycle; it adds no SCRAM authentication claim.

Its spike storage is neither vendored nor installed by production code. Its schema/helper/ACL/DDL custody is outside the existing Truss source cut and must be separately admitted.
