The planned US-048/TD-048 finite model is executable in Python and independently in TLA/TLC. Final source explores604852 reachable states, with4520858 Python transitions including refusal self-loops. TLC2.19 independently reaches604852 states (3500468 generated, no queued states or invariant failures). These counts describe a bounded three-target/two-batch/two-worker/two-fence model with eight initial change/no-op masks; they are not production throughput or unbounded correctness claims.

Nine Python mutated systems expose fence, retry, partial commit, guard race, expired admission, cancel cutoff, terminal reopening, premature cancellation and missing-lookup-as-noncommit failures. Four independently mutated TLA sources fail LiveAdmission, CompleteReceipts, FrozenTarget and ConfirmedMarker. Three equal-count stale/unsafe Python receipt controls refuse before Java dispatch. All source/tool/log/receipt digests are retained; the TLC runner checks current source and full Python receipt/status before and after its execution.

Useful traces reach both batch commits, recover an original lost COMMIT acknowledgement, retain a cancelled committed prefix, stay unresolved while the original transaction is running, and write under admitted guards before original rollback/crash-before-stop/reconciliation. The last is specifically a post-admission rollback witness, not an expired pre-lock claim relabelled as AC8.

These were addressed in the source and falsifiable controls. The initial TLA parse and sandbox runtime-listener failures are superseded by successful final-source TLC execution with a temporary checksum-verified Java runtime; no system installation was changed.
