The raw `qualification.json` is the unmodified output of the public installed-package migration gate. It preserves `sourceCommit: null` and `workflowRunId: null` because this was a local public-wheel qualification. `command.json` separately records the exact command, clean source tag, environment, output path and custody. The raw `run.log`, exit status, start/end markers, initial/final source state and package input hashes are retained.

The original run also emitted source44/source46/source47 native inventory, original-evidence and before-close snapshots, plus `PriorPublishedReceiptTests-before-close.json`. Those ten runner-created JSON files are retained deterministically gzip-compressed under the same names plus `.gz`; `migration-native-evidence-custody.json` records each original byte length/SHA and compressed SHA, and verifies decompressed bytes equal the originals. This preserves native evidence observed before cleanup without copying wheel or release archive binaries.
