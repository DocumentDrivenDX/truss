# Native anchor-to-program binding

`resolve_preparation_program_binding(anchor_id, anchor_nonce, current_data_xid)` is an owner-private PostgreSQL 18.6 identity component. It requires a writable REPEATABLE READ transaction without SET ROLE, compares the supplied full transaction ID with the actual current transaction, and requires the existing original anchor identity predicate. After the store cut it takes the program-home SHARE lock and original row lock NOWAIT. It resolves exact canonical JSON UUID bytes to the enrolled program only when the original store ID and complete store receipt also match. It returns the native program ID; it never returns packet bytes, executes SQL or mints permission.

The basic native test uses the original products acceptance, issued store and real Weft compilation/registration from `dc687366`. It creates the original pre-RR anchor under an active same-person coordinator transaction, commits control issuance, then resolves the enrolled program in a data RR transaction. Wrong nonce, unregistered program, mismatched current full XID and a different physical data connection with the same person/store/program refuse; the original comparison remains usable after the fixture savepoints. Direct ordinary execution of the private helper is denied. The test-only narrow assessor wrapper is not a production installer or permission path. One native test passed in 6.782s. Source hashes and the native log are retained under `evidence/preparation-program-binding-20261015/`; Astra Ultra approved the source in this identity-only scope.

Current-XID equality does not establish that this is the anchor's first or original data transaction: the pre-RR anchor does not retain that transaction ID. Guarded issuance must still bind the actual data XID and one-shot lifecycle, admit the original compiler/program and installed source, enforce current Subject/action/owner permissions, and independently guard selection, finalization and seal persistence through original commit/recovery. No production installer or ordinary grants are added. This component does not activate protected execution.
