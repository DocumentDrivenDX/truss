# Truss v0.0.2

Experimental Python release with end-to-end signed64 and decimal(18,4) support:
original UMF0.7/0.8 catalog acceptance, create/update/import, direct reads and
Weft queries. Integer values beyond JavaScript’s safe range retain precision;
decimals preserve original tokens and refuse rounding or overflow. Python
queries return int and Decimal.

Runtime0.39-candidate, layout0.16 candidate, matching Weft0.4.4 wheels/backend0.4.9,
DocumentDrivenDX pgserver-pg18==18.6.1/PostgreSQL18.6, psycopg3.3.6, Bun1.4.2.
The release workflow runs the installed adopter and both original-version numeric
workflows on Linux x86_64 and macOS arm64 before publication.

```sh
python -m pip install --only-binary=:all: \
  --find-links https://github.com/DocumentDrivenDX/truss/releases/expanded_assets/v0.0.2 \
  --find-links https://github.com/DocumentDrivenDX/weft/releases/expanded_assets/v0.4.4 \
  --find-links https://github.com/DocumentDrivenDX/pgserver/releases/expanded_assets/pg18.6-pgv0.8.6-r2 \
  'truss-toolkit[local,native,query]==0.0.2'
```

Existing0.38 installations require the explicit administrator-owned upgrade
before using this runtime. Original reports, receipt rows and routine custody
are preserved. Earlier supported0.23–0.38 candidates can upgrade to0.39;
modified installations and downgrade routes remain unsupported.

Bun remains required for catalog/key preparation. The wheel and source distribution
include native runtime assets; SHA256SUMS and release-pins.json identify exact
uploaded bytes and dependency pins. Weft wheels avoid a local Rust build.

Other facet combinations/evolution, structured/owned values, multi-hop queries,
retention cleanup and managed-service qualification remain unfinished. No stable
layout or complete protected-engine claim follows.
