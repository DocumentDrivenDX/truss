# Truss v0.0.24

Registration binds valid retained values to newly declared optional, non-key
scalar and flat array/map fields. Each affected object advances one version;
unmatched retained entries stay unchanged. Invalid candidates refuse with
document-qualified `property.rebind_value` counts before catalog/data changes.
Required/key rebinding and recursive values remain unfinished.

Registration-owned transitions preserve complete before/after history and exact
events. Report0.3 includes immutable effects and original event-byte wrappers;
old report bytes remain unchanged. Data-bearing reports require current read
authority over their original owners and property/item definitions, including
replay. Metadata-only catalog views retain their existing registrar contract.

Public reads, Weft scalar/complete-entity queries and committed feeds expose the
new version. Create and register can share one caller-owned transaction.
Native60 upgrades native59 additively, preserving data, original reports,
receipts, installation identity and feed state. The new storage table is
captured in UMF and installed from the UMF-owned PostgreSQL SQL exporter.

Matching Weft0.4.25 selects backend0.4.30/native60; older backend29/native59
remains separately available. Basic UMF0.7/0.8 workflows and populated upgrade
pass seven tests on PostgreSQL18.6. Astra Ultra reviewed the implementation.
Publication is confirmed only after both release workflows succeed.
