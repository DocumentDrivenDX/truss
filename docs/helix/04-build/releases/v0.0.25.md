# Truss v0.0.25

Catalog registration now binds retained values to new required non-key scalar
and flat-container fields. All existing objects must supply valid non-null
values; missing/null values refuse with document-qualified `property.required`
counts before changes. Empty containers satisfy presence. Invalid present values
retain `property.rebind_value`. Key backfill and recursive rebinding remain open.

Native61 upgrades native60 without replacing its rebinding storage. Historical
report0.3/profile0.1 bytes remain exact; new transitions use profile0.2. Public
reads, history, Weft queries and committed feeds expose the resulting versions.
Matching Weft0.4.26 selects backend0.4.31 while retaining older backend mappings.

Four basic UMF0.7/0.8 workflows and one populated native60 upgrade pass on
PostgreSQL18.6. Astra Ultra reviewed and approved the implementation. Publication
is confirmed only after the matching release workflows succeed.
