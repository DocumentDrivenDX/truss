# Truss v0.0.18 — optional binary equality

The public Python query and query-page APIs admit optional singular binary
fields in literal/typed-parameter/field equality and INNER joins. Absent and
present null retain distinct projections; both yield SQL UNKNOWN/nonmatch in
equality, while empty bytes remain a matching value.

Pins: native0.55/layout1.0, Weft0.4.20/backend0.4.25, wire0.2.5, PostgreSQL18.6
and psycopg3.3.6. The previous backend remains required-only. Timestamp
comparison, binary grouping/order and null parameters remain unsupported.

Basic UMF07/08 public workflows pass. Publication follows matching wheels.
