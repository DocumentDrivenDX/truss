# Truss v0.0.17 — binary byte equality

Adds required singular binary equality in Weft filters and INNER joins through
the public Python assembly. Use existing `TextValue(kind="binary", text=...)`
for explicitly typed canonical base64 parameters; strings remain strings.
Literal and field equality compare decoded bytes and retain original projections.

Pins: native0.54/layout1.0, Weft0.4.19/backend0.4.24, compile/IR/backend0.2.5,
PostgreSQL18.6 and psycopg3.3.6. Timestamp comparisons, binary grouping/order
and binary relationship/page keys remain outside this tranche.

Basic public UMF07 and08 write/read/query workflows and a populated immediate
0.53→0.54 upgrade passed. Astra Ultra reviewed the plan and implementation.
Publication is pending the matching release workflows.
