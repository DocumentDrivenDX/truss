# Truss v0.0.5

Experimental Python release adding compatible non-key signed64 and decimal(18,4)
facet evolution. Existing unfaceted properties can gain the exact supported maps
when all stored values satisfy them, or remove them as a widening. A narrowing
that fails returns typed `property.facets` rules and exact affected counts under
current document/module authority. Repair values through public groups, then
retry registration. Unknown maps, key-facet changes and broader transformations
remain unsupported.

Acceptance preserves object IDs, versions, timestamps, record revisions and exact
value tokens. Historical original reports and committed receipts remain readable
and replayable. Runtime0.42-candidate upgrades exact0.41 additively; layout0.16
candidate is unchanged. Matching Weft0.4.7/backend0.4.12 supports queries after
compatible refinements. PGserver-pg18==18.6.1/PostgreSQL18.6, psycopg3.3.6 and
Bun1.4.2 remain pinned.

```sh
python -m pip install --only-binary=:all: \
  --find-links https://github.com/DocumentDrivenDX/truss/releases/expanded_assets/v0.0.5 \
  --find-links https://github.com/DocumentDrivenDX/weft/releases/expanded_assets/v0.4.7 \
  --find-links https://github.com/DocumentDrivenDX/pgserver/releases/expanded_assets/pg18.6-pgv0.8.6-r2 \
  'truss-toolkit[local,native,query]==0.0.5'
```

Release workflows verify installed adopter/numeric/typed-key/traversal/refinement
workflows on Linuxx86_64/macOSarm64 before publishing checksums and source pins.
Astra Ultra reviewed the plan, scope correction and completed iteration. Full
per-object violation enumeration is a later interface tranche; current refinement
refusals report exact counts. Structured/owned values, broader evolution,
retention cleanup, stable layout and managed-target qualification remain underway.
