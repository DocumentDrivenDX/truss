# Truss v0.0.9

Adds exact typed authored-primary-key SQL pages through query_page_in_transaction.
Required string, boolean, integer and decimal(18,4) components have typed ordering
and lossless lexical continuations. Numeric result precision/token scale and
boolean tie ordering survive page boundaries; current-query context pins,
lookahead and live-per-call semantics remain.

Native0.46-candidate/layout0.16 pairs with Weft0.4.11/backend0.4.16 and upgrades
0.45 additively. Typed pages use wrapper/cursor0.2; older explicit entity-page
profiles stay string-only. No binary/timestamp/unfaceted-decimal key or managed
platform claim. Astra Ultra reviewed plan/source; basic UMF0.7/0.8, existing
string pages and upgrade checks pass on PG18.6/psycopg3.3.6.
