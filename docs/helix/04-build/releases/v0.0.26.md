# Truss v0.0.26

Catalog registration can add alternate business keys to existing records over
already-defined required scalar fields. It preserves existing key numbers,
uses original UMF exact tuples, and refuses duplicate candidates by qualified
key and affected-object count before changes. Pure key backfill preserves object
versions and history. Existing/primary key changes remain unsupported.

Immutable registration effects in report0.4 retain original receipts,
memberships, reservations and generations under current reader authorization.
Original reports retain exact bytes. Native62 upgrades the published native61
runtime; caller-owned commit and rollback semantics remain. Acceptance accepts
an optional `bun_executable` for the owner key operation.

Matching Weft0.4.27 selects backend0.4.32; older mappings remain available.
Basic UMF0.7/0.8 public lookup/query and duplicate-refusal workflows plus populated
published-predecessor upgrade are the release checks. Astra Ultra reviews source
and completion. Publication is confirmed after both workflows succeed.
