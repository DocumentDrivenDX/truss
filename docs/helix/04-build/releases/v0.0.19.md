# Truss v0.0.19 — portable binary release workflows

Supersedes unpublished17/18 candidates: their new binary fixtures inherited
a helper with a machine-specific Bun path. The shared mutation fixture now
uses TRUSS_BUN_EXECUTABLE or Bun on PATH. No product checks are skipped.

Includes required and optional binary equality through the public Python
query/query-page APIs. Native55/layout1.0, published Weft0.4.20/backend0.4.25
and wire0.2.5 are unchanged. Absent/null/empty distinctions, exact canonical
base64 and explicit old-backend refusal are retained. Release checks run the
actual wheel on Linuxx86_64 and macOSarm64 using the existing workflow.

No immutable tag is moved;17/18 are not claimed as published wheels.
