# Truss v0.0.21 — field presentation names

Registering a name-only Field change now retains property IDs, business-key identities, stored values and original receipts. Current reads, key lookup, Weft queries and updates use the new name; historical records remain revision-qualified. Existing retained values cannot be hidden by a renamed field, and names occupied in the prior catalog cannot be reassigned in the same revision, independently of member order.

Matching pins are native57/layout1.0 and Weft0.4.22/backend0.4.27. Native56 upgrades transactionally. This does not permit combined field meaning/key-facet changes or rebind occupied names.

Also corrects the unpublished v0.0.20 candidate: its numeric support policy was omitted from the retained-extension report composer, causing unknown extension content to refuse native acceptance. Both new decimal policies now preserve verified original extension occurrences. The immutable20 tag remains unchanged;21 includes its decimal(18,2) support.
