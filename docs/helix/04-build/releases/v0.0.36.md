# Truss v0.0.36

Fix deferred edge writer authorization after an early attempt-constraint flush.
Retaining reader access after writer revocation no longer permits the pending
edge write to commit. Row and transition settlement recheck the relationship
module writer and roll back the transaction when that authority is absent.

This release keeps the published v0.0.35 feature and layout scope, including the
128-operation group bound. It uses native runtime `0.70-candidate`, PostgreSQL
18.6, psycopg 3.3.6 and pgserver-pg18 18.6.1, with the same published Weft pin.
The transactional upgrade accepts the exact published native68 predecessor and
preserves existing objects, edges, journals, receipts, function OIDs and grants.

The owned-graph and 1,024-operation development tranche remains separate and
unreleased. Its performance gates are unchanged.
