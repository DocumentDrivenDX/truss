# Truss v0.0.7

Adds Weft projection of flat scalar arrays/maps and complete entities. QueryRows returns immutable tuples and key-sorted mappings with exact Python integers/Decimals, preserving numeric token precision and outer absent/null/empty meaning. No new descriptor transport is introduced; original UMF item-only Fields receive no synthetic property IDs.

Native0.44-candidate/layout0.16 pairs with Weft0.4.9/backend0.4.14 and upgrades0.43 additively. Container comparisons, unnesting and nested/owned values remain unsupported. Earlier runtime/query release pairs retain their semantics. Local PostgreSQL18.6/psycopg3.3.6 only; managed target qualification remains outstanding.

Astra Ultra reviewed plan and source. Both original UMF workflows, prior-runtime upgrade and existing exact numeric queries pass. Publication uses the release workflows and exact wheel/checksum pins.
