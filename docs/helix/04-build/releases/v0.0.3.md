# Truss v0.0.3

Experimental Python release adding exact typed business keys. Original UMF0.7
and0.8 catalogs can use required string, integer (including signed64),
decimal(18,4), Boolean and binary key components through object creation,
updates, lookup, imports and KeyAbsent preconditions. Decimal-equivalent tokens
identify the same key; original stored values retain their text.

Runtime0.40-candidate, layout0.16 candidate, Weft0.4.5/backend0.4.10,
pgserver-pg18==18.6.1/PostgreSQL18.6, psycopg3.3.6 and Bun1.4.2. Release checks run
the installed adopter, both original-version numeric and both typed-key workflows
on Linuxx86_64/macOSarm64 before publication.

```sh
python -m pip install --only-binary=:all: \
  --find-links https://github.com/DocumentDrivenDX/truss/releases/expanded_assets/v0.0.3 \
  --find-links https://github.com/DocumentDrivenDX/weft/releases/expanded_assets/v0.4.5 \
  --find-links https://github.com/DocumentDrivenDX/pgserver/releases/expanded_assets/pg18.6-pgv0.8.6-r2 \
  'truss-toolkit[local,native,query]==0.0.3'
```

Lookup values accept existing TextValue/BooleanValue carriers; bare strings remain
valid. Use fresh group/import contexts for new operations. Keep original inputs
and request keys for exact committed replay. Explicit administrator-owned upgrade
from0.39 preserves historical string routes, reservations, reports and receipts,
including old mutation-profile replay. No downgrade path is provided.

Timestamp/float key equality is undefined upstream. Weft page ordering and
relationship-key projections still require string keys. Structured/owned values,
broader evolution/traversal, retention cleanup, stable layout and managed-target
qualification remain unfinished. SHA256SUMS and release-pins.json identify exact
uploaded package/runtime/dependency bytes and pins.
