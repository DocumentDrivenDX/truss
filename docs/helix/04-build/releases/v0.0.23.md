# Truss v0.0.23

Adds precision-preserving timestamp equality through the public compiled query
API with matching Weft0.4.24 wheels. `TextValue(kind="timestamp", text=...)`
parameters, SQL literals and field joins compare exact instants across offsets,
retaining arbitrary fractional precision within the existing token bound and
the original stored text. Optional absent/null values remain nonmatches.
Query pages and read-only transactions use the same profile.

Native59 upgrades native58 additively without changing layout1.0 or existing
objects, catalog reports, receipts and feed state. Temporal business keys,
timestamp ordering/grouping and Ashlar native adoption remain separate.

The release uses the existing GitHub Actions wheel/release workflow and
Weft backend0.4.29 with compile/IR/backend0.2.6. The selected recipe is
`umf-rfc3339-exact-instant/1.0.0`, committed in UMF main. This source note does
not claim publication before that workflow succeeds.
