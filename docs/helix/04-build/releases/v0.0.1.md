# Truss v0.0.1

Initial experimental Python release, with a platform-independent wheel and source
distribution. Runtime 0.38-candidate, layout 0.16 candidate, Weft 0.4.3 distribution
with Truss backend 0.4.8, DocumentDrivenDX pgserver-pg18==18.6.1/PostgreSQL 18.6,
psycopg 3.3.6 and Bun 1.4.2.

The public assembly supports catalog acceptance/report/reader views, exact
scalar object/edge writes and reads, grouped transactions/batches/dry-run,
durable request replay/receipts, Weft queries, imports, retained history and
committed feed/ordinary-role ACK. The release workflow runs the installed basic
adopter workflow on Linux x86_64 and macOS arm64 using the published Weft/PG wheels.

```sh
python -m pip install --only-binary=:all: \
  --find-links https://github.com/DocumentDrivenDX/truss/releases/expanded_assets/v0.0.1 \
  --find-links https://github.com/DocumentDrivenDX/weft/releases/expanded_assets/v0.4.3 \
  --find-links https://github.com/DocumentDrivenDX/pgserver/releases/expanded_assets/pg18.6-pgv0.8.6-r2 \
  'truss-toolkit[local,native,query]==0.0.1'
```

Bun 1.4.2 remains required for catalog/key preparation; Rust/Cargo is not needed
with the matching Weft wheel. Tagged source contains the runnable examples.
SHA256SUMS covers the uploaded package bytes; release-pins.json records source,
runtime/layout/backend and dependency pins.

This initial release does not claim stable layout, Aurora/Lakebase qualification,
complete protected-engine activation, structured/owned values, full independent
interchange or queryable numeric facets. Signed64/decimal18,4 end-to-end support
is the next iteration, currently separate and unpublished.
