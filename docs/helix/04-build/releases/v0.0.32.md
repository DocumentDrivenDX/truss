# Truss v0.0.32

Native 0.67 derives business-key bytes in PostgreSQL for creates, updates,
preconditions, lookups, imports and catalog key backfills. Ordinary key operations
no longer encode in Python or spawn Bun, and send no per-key owner receipts.
The existing UMF tuple format, namespaces, collision checks, authorization and
transaction boundaries remain. Historical keys and contexts are not rewritten.
Selected-key allowedValues retain canonical equality; defaults do not fill keys.

UMF 0.7/0.8 native five-family support remains bounded to the admitted subset,
including decimal precision18/scale2 or4. Registration and separate protected
security observation retain their original producer requirements. Weft 0.4.32
is optional for queries and must be released first. Includes standalone scalar
admission and owned transition constraints already on main, preserving their
qualification limits. Owned-object lifecycle remains unfinished.

Local native65 upgrade checks preserve complete prior key/reservation bytes,
then perform reads and rekeying. CI verifies built-wheel workflows, both native
platforms and unchanged predecessor contexts before publication.
