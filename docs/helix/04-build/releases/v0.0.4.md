# Truss v0.0.4

Experimental Python release adding bounded direct graph traversal. The public
assembly and direct-read provider accept a typed start and1–3 qualified hops,
returning unique terminal scalar objects after all hops. Incoming/outgoing/both
directions, path-local cycle exclusion, numeric identity ordering and read-only
READ COMMITTED are supported. Logical state/result/byte limits return an explicit
limited restart result with no partial objects. This is one-call live traversal;
staged resumability, broader relationships and exact backend allocation accounting
are not claimed.

Object reads now require every property declaration owner's module access.
Runtime0.41-candidate upgrades exact0.40 additively while preserving prior data,
reports, receipts, routine custody and feed checkpoints. Layout remains0.16
candidate. Matching Weft0.4.6/backend0.4.11 retains exact numeric query support.
PGserver-pg18==18.6.1/PostgreSQL18.6, psycopg3.3.6 and Bun1.4.2 remain pinned.
