# Original conformance service construction port

Private implementation dependency for CONTRACT-011/C1. The public factories
retain their existing configuration plus HostConformanceRunner/Assessor
signatures. A matching structural object is not original registered service
custody. This proposal specifies the missing startup-to-construction handoff;
it does not implement or qualify a runner, assessor or registry.

The existing trusted host composition establishes original service registration
before factory invocation. Its admitted original build/function/procedure and
resource artifacts, nonempty manifest/qualification approvals and environment
references must already be available in retained local custody. Construction
cannot fetch artifacts, load modules from case content, call a service or acquire
native resources to establish those facts.

The private construction dependency resolves an exact original service object
and role to its issuer-bound startup registration. It returns captured original
method references, exact runner/assessor and resource profiles, registered build
and function correspondence, and immutable approved configuration. The runner
registration additionally binds originalComposition, procedure/environment
registration and complete allowed manifest/reference inventory. Assessor
registration binds the independent qualification-profile/manifest inventory.
Registration is supplied by the existing host authority; the dependency does
not decide whether a receipt qualifies.

Recognize custody through a private issuer-bound association established by that
startup path. Neither public object fields, a copied registration artifact,
matching digest, JSON serialization nor the TypeScript interface can create it.
No public register/arbitrary-callback method is added. If a host cannot supply
original registration, construction returns incompatible_service; it must not
quietly accept structural equality as a temporary implementation.

Verify the exact selected supported construction version and complete original
configuration against that registration. Preserve original method receiver and
function identity, then freeze the captured projection. Later replacement of a
host object's methods or mutation of caller configuration cannot change the
issued tooling's registration. Required live authority/generation checks still
belong to original prepare/run/assessment procedures; construction does not
cache permanent authorization.

Prepared-run issuance, at-most-once claim, abandonment and recovery remain owned
by the original host runner. The wrapper passes original prepared custody through
and never issues a replacement handle, interprets a recovery string as authority
or starts work during reconciliation. Assessment remains the original independent
assessor's decision; recorded execution cannot be converted into qualification.

Independent C1 controls must present a method-shaped fake service, a shallow
copy of an issued service, swapped runner/assessor registration, changed build
or function correspondence, unsupported construction version, duplicate or
conflicting approvals and empty environments/manifests. All refuse with zero
service/native/artifact-resolution calls. A positive original projection also
has zero construction calls; explicit later invocation uses the captured
original method/receiver. Mutating configuration or replacing host methods after
construction must not redirect execution. Missing live authority at invocation
refuses through the original service rather than weakening its boundary.
