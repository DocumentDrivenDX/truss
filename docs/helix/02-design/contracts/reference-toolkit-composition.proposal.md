# Reference toolkit composition proposal

This is the integration map for the existing `truss-reference-assembly/0.1.0` configuration and capability interfaces, not a new public assembly API. It consumes CONTRACT-001–012, the criterion-level design audit and the existing reference definition/policy/history proposals. Status: proposed composition; no complete installed bundle or public runtime qualification is asserted.

## Reference direction and independent profiles

Use the current 0.15 qualified-property model as the catalog identity source for new composition work. Retain its original declaring-document/module/Field identity and ordered key correspondence. This is a component basis, not an installable complete layout. The separately registered 0.11 Weft compiler fixture remains pinned to its original model/statement/mapping bytes until an explicit new registration qualifies the changed composition. Do not silently call the new composition 0.11, overwrite its fixtures, or combine a 0.15 column selector with an old native descriptor.

Use the existing pg-runtime connection source for the Node reference executor. Keep Python orchestration and a possible Bun adapter behind the same language-neutral contracts, with independent original transport and transaction evidence. The security owner supplies native identity, authorization and current-authority publication protocols. Truss supplies operation/storage composition and consumes those protocols; no second identity registry or ACL resolver is introduced.

### Admission steps

1. Capture exact original source/profile bytes for each selected capability and distinguish already selected product behavior from proposed implementation profiles. Preserve current pending human choices separately.
2. Resolve every required producer and its owned dependencies, including original native authority/executor and resource procedures. Record an unavailable producer as an incomplete capability; never insert fabricated native identities or qualify through a placeholder.
3. Build immutable definition artifacts in the existing acyclic composition order. Recursive logical UMF types do not create permission to introduce cyclic exact-byte artifact references.
4. Reconcile the complete physical model using CH-01, including implicit effects, administrative initialization and native/security dependencies. Generate through the existing UMF backend with exhaustive ordered coverage.
5. Independently review original definition/descriptor/inventory agreement in both directions, then execute the corresponding native acceptance and bypass tests. Source-complete and native-qualified are distinct conclusions.
6. Activate only the exact admitted capability closure under existing protected publication procedures. Assembly construction stays inert; readiness observation does not migrate, manufacture grants or authorize operations.

## Incompatible combinations to refuse

- A 0.15 qualified Field identity with an old unqualified property selector or Weft registration.
- A complete-history/feed claim with legacy partial payloads, absent metadata witnesses, missing original fact times or only journal-row counts.
- Receipt replay reconstructed only from journal changes, omitting no-op results, or enabled by caller scope/hash alone.
- A protected key/home reader treated as ordinary public SQL without its selected original caller/authority custody.
- A declared database key guarantee whose ordinary canonical writer can omit or forge derived key rows.
- A fresh-install bundle used as an upgrade over retained data, or startup inspection used to repair a mismatch.

Independent integration tests must deliberately construct each incompatible combination and observe refusal before capability publication/effects. For valid combinations, compare complete original input/output/inventory and native outcomes, not merely matching version labels. These tests are required future implementation exits, not claims of executed conformance.

## Remaining concrete selections

Select the original native producer/resource/authority profiles for each row; reconcile one complete physical model and exact supported release/environment range; finish language-neutral case/adapter grammar. Existing pending human decisions cover Python package ownership, traversal terminal-versus-path output and pre-effect continuous-writer admission retry. Preserve those questions rather than inferring an answer here. Optional traversal can remain unavailable while unaffected toolkit work proceeds, but its broader required design remains open.

This proposal does not shrink full toolkit scope to the scalar reference milestone or a single compiler fixture. Broader exact recursive values, supported relationships, complete history/feed and consumer Python interchange retain their governing requirements and independent qualification exits.
