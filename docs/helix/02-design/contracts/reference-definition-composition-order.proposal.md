# Acyclic reference definition composition

The presence artifact's valueDefinition must identify the original scalar value-shape leaf, not the composite truss-reference-row-value artifact. The composite references presence and scalar codec; the codec references presence. Pointing presence back to that composite would create an exact-byte/hash cycle that cannot be constructed by the intended immutable artifact procedure. Placeholder shape fixtures cannot prove such a graph realizable.

Select a distinct authored scalar-shape leaf for each original Field. It retains the complete qualified Field identity, scalar family, admitted scalar/null root alternatives, scalar payload dispatch and original accepted/authored/physical source artifacts. It contains no presence, scalar-codec or composite-row-value artifact reference. Absence remains the presence definition's complete zero-state interpretation, not a scalar-shape node. Required code/amount leaves admit scalar roots only; Item.note's selected leaf admits scalar and explicit null roots, with null carrying no payload.

Construct the bundle in this order:

1. Retain the original full UMF source and accepted interpretation/context, original physical/home and authority/resource/source-domain dependencies. Native identity fields require original observations later; draft labels never fill them.
2. Construct each original scalar-shape leaf from those independently admitted prerequisites. It contains no downstream artifact dependency.
3. Construct the presence artifact, whose valueDefinition is exactly that leaf. Verify original Field/family/root/null/home agreement, not just its hash.
4. Construct the scalar codec with the exact completed presence bytes and its source/native/resource definitions. It does not refer to the composite value.
5. Construct the original row-join descriptor and composite row-value artifact with completed presence/codec/home/source bytes. Independently compare the leaf reached through presence with the composite's Field/family/root and physical claims.
6. Admit the complete bundle atomically, including full original Record/key/relationship and native/authority/resource/compiler prerequisites. Topological construction does not authorize partial activation.

No hashing fixed point, omitted bytes, digest-only placeholder, mutable registry pointer or post-hash patch is permitted. ExactArtifact still carries full original bytes plus its verified digest. Recursive logical UMF types remain owner-defined source meaning; this artifact custody DAG is not an invented prohibition on recursive logical schemas. The leaf is a reference scalar milestone format and cannot describe broader recursive/mixed-home support by relabeling.

Independent controls must refuse presence pointing at the composite, a leaf with a downstream artifact reference, a different original Field's leaf, wrong scalar/null alternatives, mixed physical source and a post-hash patch. A same-name Field cannot supply identity agreement. Retain ordinary complete bundle and zero/one-over resource controls: duplicate embedded source bytes and repeated visits still charge the original account. These controls are planned; no accepted/native definition instances or compiler registrations are manufactured by this construction order.


The [closed scalar-shape leaf schema](truss-reference-scalar-shape-v0.1.proposal.schema.json) fixes identity, family, root alternatives and original accepted/authored/physical custody. It declares no presence, codec or composite reference fields. Decimal null refuses in this reference format; Item.note's string leaf requires its original explicit-null interpretation. Full resolved bytes must still be checked for the exact original dependency roles and acyclic composition; opaque artifact shape and digest equality cannot establish that semantic graph. No native/accepted instances are emitted by this schema.

## Complete original bundle admission procedure

Start from the submitted original composite definitions for all four required Fields and their complete admitted Record context. Reserve the complete known input/copy/diagnostic traversal bounds before decoding artifact payloads. Resolve ExactArtifact by comparing full decoded bytes and verified identity/digest under the selected byte grammar; a hash route or cache hit alone supplies neither authenticity nor semantic interpretation. Account for every retained embedded copy, even when repeated content is identical.

Build the original dependency inventory from the exact known definition formats and their declared artifact slots. Track each original artifact's visitation state (unvisited, active, complete) and retain the exact edge/slot that introduced it. Encountering an active artifact through a declared dependency is a cycle refusal, not permission to truncate traversal or replace bytes with a registry pointer. Unknown format/profile meaning refuses interpretation while preserving original content; do not discover dependency semantics by scanning arbitrary strings for matching hashes. Logical recursive UMF references belong to the admitted source interpreter and are not custody-artifact dependency edges.

Resolve leaves before dependents. Check each accepted/authored/physical leaf's original role and Field/source/installation correspondence, then scalar-shape identity/family/root alternatives; presence's leaf and null/absence meaning; codec's exact presence and native/source/resource domain; row-join's exact physical selector/custody; and composite's full agreement with all those artifacts. A completed node may be reused only with full original context/profile agreement; performed repeated byte visits and copies still charge the same original account. Reuse cannot turn one Field's artifact into another Field's definition.

Before publishing registration, independently compare the complete actual four-Field inventory with the original accepted Record/member inventory in both directions. No missing note, extra Field, same-name substitute or incompatible retained state is permitted. Admit original keys/relationship/source and current authority, complete physical/home/native parser/codec/resource and compiler capability prerequisites for each advertised operation. Direct-read admission never implicitly registers compiled null support. Preserve broader product requirements as separate required profiles rather than claiming this scalar bundle covers them.

Registration publication is one original protected transition. Publish no partial Field, presence or codec capability while a sibling remains unresolved. On any failure retain the original active registration; confirmed rollback and unknown native settlement follow their original distinct executor procedures. A source-only construction run emits proposed artifacts for review and never updates the active registry. This design introduces no new public registry method and does not choose a native OID, producer build or authorization service.

Independent semantic controls cover exact self/back cycles, shared acyclic leaves with distinct original contexts, digest collisions with different bytes, altered payload under unchanged digest, source/Field substitution, unknown dependency format, incomplete four-Field inventory, unsupported compiler null and failure immediately before/after protected publication. Complete native/authority/resource producer qualification remains separate. Placeholder schema controls cannot satisfy these cases.
