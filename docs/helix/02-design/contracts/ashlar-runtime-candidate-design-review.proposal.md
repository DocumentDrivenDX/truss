## Driver profile distinction

The candidate host bridge pins pg 8.16.3. The planning predecode integration reviewed a different frozen pg 8.23.0/pg-protocol 1.16.0 source tuple. Do not transfer that review to this bridge. The candidate uses pg Result fields, safe numeric rowCount and converted row strings, which can support its explicitly observed small subset but cannot supply original RowDescription/CommandComplete/ReadyForQuery capture, predecode UTF-8/allocation evidence or complete native response enumeration required by the selected bounded profile. Implement the private producer port or qualify another explicitly selected equivalent transport; a safe numeric count is not retained original command-count text.

The candidate has no automatic retry loop: retry classification requests whole-transaction retry. Its deferred rejection path separately submits ROLLBACK before classifying known rejection; unknown COMMIT remains quarantined. Keep these distinctions and test their original native evidence when moving beyond the current fixture subset. Callback return, savepoint release and a driver command name cannot publish pending IDs as committed graph results.

## Smallest complete protected producer dependency chain

1. **Original issuer and codecs.** Exact installation/layout/profile observations, original native xid and monotonic ordinal producer, actor capture under CONTRACT-005, immutable context/input/prestate/effect/group codecs, shared account and E06 arbitration. Bind actual native producer membership and all ordinary privilege exclusions. Neither fixture bytes nor helper booleans implement this unit.
2. **Protected operation admission.** Complete original actor/authority and finite capacity reservation, immutable admitted scope, required global/policy/catalog/endpoint exclusion hierarchy, registry insertion and surviving savepoint custody. Include at-most-one unfinished invariant and immutable finalized entries. Ordinary roles cannot write registry/capacity/touch/stage state or directly invoke private admission/phase routines.
3. **row_touch_observe and generation contribution.** Installed unavoidable observers on every selected state/node/scalar canonical event resolve the original unique unfinished operation, check actual relation/event/OLD/NEW and original scope, then record full contribution and invalidate prior generation proofs. Own the exact observer dependencies/rights/search path with its body. Bind direct, indirect, replication, disablement and administrative paths; private trigger-only invocation is no public API.
4. **Complete finalization and deferred row check.** Whole original owned rows and all non-row obligations, independent participation checks and marker/canonical parity, complete journal capture/publication and original row/operation phase transitions. The deferred dispatcher uses the full surviving transaction cohort, including earlier finalized operations. row_touch_commit_check cannot be implemented as trusting a seal flag.
5. **Complete-feed producer and current union.** Original feed transaction/member/prerequisite/configuration identities and clocks/ordinals, original canonical/catalog contributions and unavoidable feed triggers, exact member-count/finalization procedure and feed_union_validate_current_scope/feed_current_union_check. Preserve complete configuration/catalog prerequisites and zero-data transactions where required. Count equality alone cannot prove authentic membership or source authority.
6. **Public feed and ACK/fencing.** Current qualified consumer/configuration generation, complete bounded discovery/fragment/reassembly/protection/restart and safe-watermark observation. Worker claims and descriptor-bound verified application evidence govern ACK; a successful partial downstream application cannot advance source checkpoint. Use fresh current authority and original uncertain-attempt recovery throughout.
7. **Atomic installer/security admission.** Compose original declaration/body/trigger/policy/grant/dependency inventory and independent effective access observations before capability readiness. Preserve original 0.12 source and complete product requirements. Component fixture success cannot publish the normal installation ready marker or label the complete feed operational. Explicit component test profiles may report their narrow results without substituting them for required Truss support.

This is the minimum closed chain for protected graph mutation coupled to complete feed, not a request to install seven disconnected fragments. Bootstrap/UMF acceptance and public mutations supply original accepted IDs/reports/head and graph effects; they cannot use fixture catalog IDs. Existing STP-044 OC/savepoint/commit/driver cases, STP-040 participation, STP-045 security/install and the complete feed/recovery corpus remain required. Keep probes small; no scale benchmark is needed to establish these boundaries.
