# TD-027: Language-neutral implementation corpus

**Story:** [[US-027]]. **Parent:** [[SD-007]]. **Feature:** FEAT-007.

## Technical Approach

Publish normative behavior and fixture schemas independent of TypeScript implementation details. Each case declares setup, operations and independently authored expected results/state/journal/report; expected SQL is informative. The runner maps opaque generated IDs through declared aliases and compares typed semantic identities rather than allocator-specific numbers. Reviewed contracts, not reference code, resolve behavior.

## Component Changes

| Planned files | Responsibility | Criteria |
| --- | --- | --- |
| `packages/conformance/src/corpus/schema.ts` | Validate complete versioned case shape and required semantics | US-027-AC2 |
| `packages/conformance/src/corpus/aliases.ts` | Stable alias binding and reference normalization without masking errors | US-027-AC3 |
| `packages/conformance/src/corpus/runner.ts` | Execute adapter-neutral operations and compare normative outputs | US-027-AC2, US-027-AC3 |
| `tests/conformance/corpus.test.ts` | Independent fixture/refusal/alias permutations | All criteria |

US-027-AC1 also requires a contract audit/walkthrough by an implementer using only published contracts. A test parser cannot prove specification completeness.

## API/Interface Design

CONTRACT-004 owns manifest/case/adapter/pass rules; CONTRACT-001–009 own behavior. Consume the existing conformance manifest/assessment/run-result wires. The [alias comparison procedure](../../03-test/conformance-alias-comparison.proposal.md) now authors typed one-time binding, injectivity, grammar-declared substitution and pre-normalization invariant checks. The [closed alias artifact wire](../contracts/conformance-aliases-v0.1.proposal.schema.json) now supplies the candidate encoding; case operation/expectation and identity-path grammars, exact original namespace interpretation and runner handshake/profile registration still require composition before execution; do not create a second manifest merely because the runner is unfinished. TypeScript helper APIs are implementation conveniences, not the language-neutral specification. Proposed ADR-003 governs future independent implementations.

## Data Model and Integration

No DDL. Corpus separates expected generated identity aliases from meaningful authored keys and version/position relationships. Normalize only declared opaque allocations; preserve collisions, wrong endpoint links, missing rows and order differences as failures. Native state/journal observers remain independent of implementation under test. Fixture expected outcomes cannot be generated by production logic.

## Security and Performance

Corpus content cannot select executable import paths or live endpoints. Trusted harness chooses adapter and disposable resources. Bound case size and recursive content explicitly. Runner cleanup/reporting preserves failures. Harness performance is separate from Truss benchmarks and cannot remove required expensive cases silently.

## Testing

STP-027 allocates criteria. Use two allocator permutations with identical semantic state and a deliberately wrong endpoint alias that must fail. Missing expected sections, malformed references and contradictory fixture expectations fail validation/review. Unknown required semantic cases cannot be treated as not-applicable while claiming full conformance.

## Migration and Rollback

Version corpus/schema/profile independently. Retain prior fixtures and accepted decisions. New case expectations need explicit traceability/review; correcting a defect does not rewrite historical run receipts. Unsupported newer case semantics refuse full-profile qualification rather than skip to green.

## Implementation Sequence

1. Reconcile unknown-case policy and complete language-neutral contracts/runner schemas.
2. Author independent cases and red shape/alias/refusal tests.
3. Implement schema/normalizer/runner, then native observer comparisons.
4. Perform contract-only implementation walkthrough and record missing behavior findings.

## Risks and Gates

US-027 now distinguishes unselected optional tags from required unknown semantics; preserve this aligned rule in manifest validation. Exact alias equivalence must not erase wrong identity relationships. Material missing contracts remain gates for AC1; existence of document headings cannot prove buildability from contracts alone.
