# Actual prepared-model and native source correspondence

This unexported candidate consumes the actual issued Weft presence preparation,
using its feature-gated requirements factory and original parent. It captures
native sources through the original stock cursor, then joins issued qualified
Record/member/ordered-Key requirements to the actual accepted native catalog.
It is incomplete data, never a native authority or guarded-release witness.
No current registration, default dependency, consumer or computation is changed.

## Construction and custody

`capture_native_model_correspondence_with_cursor(cursor, *, current,
accepted_request)` accepts the actual native CurrentPresencePreparation type,
not supplied requirements JSON or a caller callback. Its original parent is
retained and checked before/after the join using the existing native methods.
The issued requirements and exact preparation report hashes must correspond.
Original module pins and document strings must match the accepted source in
original order. Native source capture reuses the existing observer0.2, its
original assessor and stock host transaction containment. Required host source,
DDL/routine/caller/authority fences and closing guards remain separate.

The returned immutable data object retains actual current/parent references,
all original observation bytes and requirements bytes. Its report always has
complete/authority/securityReady=false and nativeAdmission=required. Constructing
or importing equal data cannot issue permission, continuity or a native witness.
It must never be accepted as a witness argument by a later protected executor.
Persistent descriptor D precedes the actual request/context and is independent
of this operation-specific report/hash; no self-hash feedback or placeholder
re-preparation is permitted.

## Exact join

For each issued Record, require exactly one active, nonprovisional native Record
with the same qualified source identity. Within that Record, require exactly
one native property for every issued complete Field identity and no extra active
members. Preserve each requested Field separately from nested descriptor nodes.
This first realization requires one original scalar descriptor, matching family
and availability labels, nonnullable singular JSON properties and the observed
original object/id/type_id/props columns. Unsupported row/column/structured or
nullable realization refuses the whole join even with no object rows.

Require one native selected key_id, positive native key_num and exact ordered
prop_ids corresponding to the issued ordered complete Key Field identities.
Additional unselected native Keys are retained in original sources. Never sort
components, select a different Key, collapse duplicate identities or infer a
codec from native IDs. Preserve native facets and original descriptor graphs
in their original byte surfaces; this join does not interpret or prove their
full domain/comparator/codec equivalence. Native key namespace/bytes, graph and
context correspondence remain required independently.

The data report records complete logical identities, native type/property/key
IDs, observed object relation/column slots and hashes of exact sources. Unknown
extension content remains in original model/request/requirements/native sources.
No supplied native inventory, report or matching hash replaces actual capture.

## Limits and validation

Existing observer four-source caps each4,000,000 bytes remain unchanged; issued
requirements use a separately named strict decoder capped16,000,000 bytes;
all existing owner-evidence entry points retain their8,388,608-byte cap, and the
mapping report cap remains4,000,000. Duplicate keys, finite numbers,512-character
numeric tokens,4096-item containers,depth128,1,000,000nodes and Unicode-scalar
checks are shared unchanged. An actual issued scalar-only requirements report
of9,833,820bytes from a597,992-byte original request demonstrates why the distinct
profile is needed; this is compiler/decoder capacity evidence, not complete
native join or owner-semantic admission. These are logical retained-byte limits, not peak-memory
or pre-materialization wire guarantees. Original legacy diagnostic budget is
separate. Host deadline checks surround compiler calls and each Record join.
Any mismatch refuses without partial mappings or automatic retry authority.

NSB-T01/T03/T04/T09/T13/T14 require independently authored positive mappings,
full-identity/duplicate/Key-order/source mismatch controls, optional absence,
unsupported-home and empty-population refusal, exact raw-byte retention,
feature absence/wrong receiver/parent identity and deadline failure. Native
execution must use the actual issued preparation and original host with no
source-provider substitution. Initial failures and exact source/toolchain pins
must be retained. NSB-T07/T08/T11/T12/T15/T16 and all graph/codec/authority/release
obligations remain open. Full Truss132/shared158cases/34criteria remain required;
45implemented/113missing is unchanged and this component promotes no case.
