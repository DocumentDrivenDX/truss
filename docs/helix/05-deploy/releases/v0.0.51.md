# Truss v0.0.51

Published on 2026-10-27 through the [immutable GitHub release](https://github.com/DocumentDrivenDX/truss/releases/tag/v0.0.51)
and [PyPI](https://pypi.org/project/umf-truss/0.0.51/). The
[final publication proof](../evidence/truss-0.0.51-publication/README.md)
retains the original exact-tag Linux and Actions OIDC/public-consumer receipts.

## Release scope and highlights

The Python distribution is `umf-truss==0.0.51`. The `truss` import, CLI entry
points and runtime protocols retain their identities. The release preserves the
existing PostgreSQL 18.6 runtime, embedded UMF JavaScript/V8 owners and selected
`weft-sql==0.4.51` dependency. Existing query/disclosure source archives keep their
exact compiler identities.

Python users receive a universal wheel and source archive through GitHub and
PyPI. Host applications continue to own authenticated connections, transactions,
connection pools and admission of the installed dependency cohort.

## Changes and fixes

Release and OIDC publication paths select the distribution/archive name by
version. Historical `truss-toolkit` archives and receipts retain their original
meaning. New-name publication requires an actually immutable GitHub release;
the fresh public-index consumer checks the exact declared query dependency.

The migration index retains the exact published 0.0.50 index, SHA-256
`4c6baf0282e3d0b5492f070c9c07d89ff0c9a819e748f3820f60b11c1f51c7aa`, and the
original public 0.0.50 wheel is an existing-current fixture. Earlier immutable
recipes, admitted sources and native SQL remain unchanged. No physical migration
edge or receipt is fabricated for this package rename.

## Required actions

Use the new distribution name in dependency declarations and retain
`import truss`. Install in a fresh environment because the old and renamed
packages provide the same import tree:

```sh
python -m pip install 'umf-truss[native,query]==0.0.51'
```

Local PostgreSQL installation remains a separate optional runtime flow with its
published binary constraints; the host-supplied connection path does not require
that local-server extra.

## Migration and hold guidance

Only the latest Truss application runtime is supported. Every admitted database
lineage retains its explicit forward path to latest; old application runtimes do
not remain supported. Pre-0.10 UMF sources and downgrades remain unsupported.
Startup never automatically upgrades or resets a database.

The 0.0.49/0.0.50 native tuple remains current without an artificial migration.
Older admitted sources use the existing explicit administrative migration flow.
Preserve original receipts and use the latest tool to verify the target. Hold
an application rollout when its actual installed cohort or native verification
fails; do not rewrite retained evidence to make it appear current.

## Qualification and known limits

[Exact-tag Linux run 40549597103](https://github.com/DocumentDrivenDX/truss/actions/runs/40549597103)
passed at normal merge/tag source `26c1b9171718ad0f6291b82f65c8cef0406886fb`:
108 populated migration/existing-current cases, 62 HF cases, 174 managed-grant
tests, all without skips, plus the required remaining installed workflows and
selected small public workload. GitHub release `425804959` has 17 immutable
assets. Automatic [Actions publisher 40555332184](https://github.com/DocumentDrivenDX/truss/actions/runs/40555332184)
passed actual OIDC upload, exact public served-byte checks and a fresh
public-index `[query]` install importing Truss and Weft 0.4.51. Independently
downloaded PyPI wheel/sdist bytes equal the GitHub release assets.

[Candidate Linux qualification](../evidence/truss-0.0.51-candidate-linux/README.md)
binds source `f3fc953814f71fe4c8e4abaa86b762a51b53add0` to 108 populated
lineage/existing-current cases, 62 independent HF cases and 174 managed-grant
tests, all without skips, plus the complete remaining installed native workflows
and selected small public workload. That earlier source and its candidate
receipts remain distinct from the final merged/tagged source and publication
receipts above.

The tested native profile is Linux x86_64, Python 3.11, PostgreSQL 18.6 and the
recorded exact dependencies. CI runs on Linux only. The universal Truss wheel
and selected public macOS ARM64 Weft 0.4.51 wheel remain available. Historical
macOS evidence retains its original versions and scope; it does not qualify
Truss 0.0.51 installed execution or populated migrations on macOS. Managed
Lakebase acceptance and broader performance/platform claims remain separate.

Weft 0.4.55 adoption is deferred until a preserving consumer-archive migration is
qualified. Replacing compiler identities alone would strand stored 0.4.51
query/disclosure archives. Truss retains its exact embedded UMF JavaScript
bundles; Core 0.10.3's Python release is not a new Truss Python dependency or
permission to repin those bundles.
