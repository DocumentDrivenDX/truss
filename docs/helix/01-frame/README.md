# Frame

Translate the product vision into requirements, features, user stories,
and project concerns using the installed HELIX templates.

[Project concerns](concerns.md) record the initial selections implied by the
[product vision](../00-discover/product-vision.md): TypeScript on Bun for the
language runtime and PostgreSQL as the first backing engine.

The [research plan](research-plan.md) defines a time-boxed storage bake-off:
per-type tables generated by UMF (option A) against generic catalog storage
with one JSONB property map per object (option C). Its findings, as SPIKE-002,
feed a storage ADR and the scope of the PRD.

The [PRD](prd.md) frames truss in 50 functional requirements across eight
subsystems. The [feature registry](feature-registry.md) lists the eight
feature specifications in [`features/`](features/), which cover every
requirement, and the 39 user stories in [`user-stories/`](user-stories/). Each
story's acceptance criteria have test scenarios. Deferred work is in the
[parking lot](../parking-lot.md).

Status: the storage bake-off ran as
[SPIKE-002](../02-design/spikes/SPIKE-002-storage-bake-off.md), and the owner
accepted its recommendation in
[ADR-002](../02-design/adr/ADR-002-storage-strategy.md). The PRD, features and
stories are drafts awaiting the owner's review. The PRD's proposed scale and
latency targets need agreement, and its five open questions need answers; each
question carries a recommendation. No separate principles document exists; the
project's standing rules are the boundaries in `AGENTS.md` and the
[concerns](concerns.md).
