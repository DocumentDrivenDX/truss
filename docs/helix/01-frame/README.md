# Frame

Translate the product vision into requirements, features, user stories,
and project concerns using the installed HELIX templates.

[Project concerns](concerns.md) record the initial selections implied by the
[product vision](../00-discover/product-vision.md): TypeScript on Bun for the
language runtime and PostgreSQL as the first backing engine.

The [research plan](research-plan.md) defines a time-boxed storage bake-off:
per-type tables generated by UMF (option A) against generic catalog storage
with one JSONB property map per object (option C). Its findings, as SPIKE-002,
feed a storage ADR and the scope of the PRD.

Status: bake-off executed as
[SPIKE-002](../02-design/spikes/SPIKE-002-storage-bake-off.md), which
recommends option C; the owner accepted that recommendation in
[ADR-002](../02-design/adr/ADR-002-storage-strategy.md) on 2026-10-03. The PRD,
feature specifications, user stories and principles have not been written.
