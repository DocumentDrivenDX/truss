Published package / local PostgreSQL 18.6

Run a private Truss instance

With uv installed, run the published Truss 0.0.46 launcher in an isolated Python 3.11 tool environment. The first run may download Python and package wheels.

uvx --no-config --isolated --python 3.11 \
  --constraints https://github.com/DocumentDrivenDX/truss/releases/download/v0.0.46/isolated-runtime-constraints.txt \
  --find-links https://github.com/DocumentDrivenDX/truss/releases/expanded_assets/v0.0.46 \
  --find-links https://github.com/DocumentDrivenDX/pgserver/releases/expanded_assets/pg18.6-pgv0.8.6-r2 \
  --from 'truss-toolkit[local,native]==0.0.46' \
  truss-local-postgres \
  --data-dir "$HOME/.local/share/truss/beads" \
  --install

The launcher supplies PostgreSQL 18.6 in private per-instance data and Unix-socket directories. It needs no system PostgreSQL, administrator access, TCP listener, or port configuration. It stays in the foreground; Ctrl-C stops the server and retains data. Run the same command with the same directory to restart. Add --probe to install or confirm Truss and stop while retaining data.

This provisions a local database and Truss schema/routines, not an HTTP, MCP, or TrussRPC application service. Tools still embed the Python library, connect with an ordinary identity, and register their UMF documents. Public business-role and module-access configuration remains separate.

See the 0.0.46 release notes, local validation record, and Python 3.11 receipt. The published-package check verifies two independent instances and retained restarts outside a checkout. For source development, use the checkout wrapper.
